# Button

Buttons lösen eine Handlung aus und nennen sie im Text, etwa "Artikel lesen" oder "PDF herunterladen".

- **Primär** in `nachtblau` mit `ink-invers`, Hover `nachtblau-700`. Höchstens ein Primärbutton pro Abschnitt.
- **Sekundär** mit 1px Kontur in `ink`, transparent auf `surface`.
- **Textlink** in `gold-text` mit goldenem Punkt davor, für "Mehr lesen" in Karten.
- Schrift im Stil `button` (Inter 15px), Ecken `radius-sm`, Höhe 44px, Innenabstand `space-4`.
- Fokusring 2px in `fokus` mit 2px Abstand.
- Im dunklen Thema bekommt der Primärbutton eine Kontur in `ink-invers-muted`, weil Nachtblau dort fast dem Seitengrund entspricht.
